# Student Performance Analytics System

## Project Overview
A Python-based data analysis project that reads student records and analyzes marks and attendance using Pandas and NumPy.

## Technologies Used
- Python
- Pandas
- NumPy
- CSV dataset

## Required Features Implemented
1. Student dataset with Student ID, Name, Department, Machine Learning, Java, Mathematics, Operating Systems, and Artificial Intelligence marks and Attendance.
2. Pandas DataFrame loading and organization.
3. NumPy numerical calculations.
4. Reusable functions.
5. Loops and conditions.
6. Total marks calculation.
7. Average marks calculation.
8. Grade assignment.
9. Pass/Fail identification.
10. Highest, lowest and average performance.
11. Subject-wise performance analysis.
12. Top-performing students.
13. Clear final output.
14. Analysis output CSV generation.

## Grading Rule
- A+ : 90 and above
- A  : 80–89.99
- B  : 70–79.99
- C  : 60–69.99
- D  : 50–59.99
- F  : below 50

## Pass Rule
A student passes when:
- Average marks are at least 50, AND
- Attendance is at least 75%.

## Project Files
- `main.py` – runs the complete analysis
- `main.py` – reusable calculations
- `student_data.csv` – source dataset
- `student_results.csv` – generated analysis result
- `Project_Documentation.pdf` – project documentation

## How to Run
Install dependencies:
```bash
pip install pandas numpy
```

Run:
```bash
python main.py
```

The project creates `student_results.csv` automatically.
